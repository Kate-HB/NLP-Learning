# NLP Learning

定位：系统理解 NLP，并用项目验证每个阶段。

## 学习主线

- 每天 5 小时：3 小时理解，1.5 小时代码，0.5 小时笔记。
- 8 周完成 NLP 基础、Transformer、BERT、GPT、Embedding、RAG 和应用整合。
- 每天写 `notes/dayXX.md`，末尾必须有 `## 今日知识总结`。
- 每周完成一个可检查产出。

## 8 周目标

| 周 | 主题 | 项目/实验 |
|---|---|---|
| Week 1 | Hugging Face 入门与 Tokenizer | 手动推理 |
| Week 2 | PyTorch 最小训练基础 | 最小分类训练 |
| Week 3 | 深度学习概念与 Transformer | Attention 小实验 |
| Week 4 | BERT 微调 | P1 中文文本分类 |
| Week 5 | 传统 NLP、BERT 与序列标注 | TF-IDF baseline + NER demo |
| Week 6 | GPT 与生成 | 生成策略对比 |
| Week 7 | Embedding 与 RAG | P2 RAG 文档问答 |
| Week 8 | LLM 应用整合 | P3 LLM 应用 Demo |
