# NLP 学习路线（56 Days Roadmap）

> **一个大语言模型时代的 NLP 系统学习路线。**
>
> 从零开始，用 **56 天**构建扎实的自然语言处理基础，并完成能够展示在 GitHub 的高质量项目。

---

## 📖 项目简介

近年来，大语言模型（LLM）和 Agent 技术快速发展，但它们都建立在自然语言处理（NLP）的基础之上。

很多初学者直接学习 LangChain、Agent 或各种 AI 应用框架，虽然能够快速搭建 Demo，却难以理解模型背后的原理，也无法回答模型设计、训练方法和算法思想等问题。

本项目希望通过一条循序渐进的学习路线，帮助学习者：

- 建立扎实的 NLP 理论基础
- 掌握现代深度学习 NLP 方法
- 熟练使用 PyTorch 和 Hugging Face
- 阅读 Transformer、BERT、GPT 等经典论文
- 独立完成多个高质量 NLP 项目
- 为后续学习 RAG、Agent、LLM 微调等方向做好准备

---

# 🎯 项目目标

完成本路线后，你应该能够：

- ✅ 理解自然语言处理核心概念
- ✅ 熟练使用 PyTorch 进行 NLP 开发
- ✅ 理解 Transformer 的整体结构与实现原理
- ✅ 阅读并理解 BERT、GPT 等经典论文
- ✅ 使用 Hugging Face 完成模型微调
- ✅ 完成多个可展示在 GitHub 的 NLP 项目
- ✅ 为学习 LLM、RAG、Agent 打下坚实基础

# ⏳ 学习安排

- **总学习时间：** 8 周（56 天）
- **建议每天学习：** 约 5 小时
- **预计总学习时间：** 约 280 小时

| 内容 | 时间 |
|------|------|
| 理论学习 | 1 小时 |
| 代码实践 | 2 小时 |
| 阅读源码 | 1 小时 |
| 总结与笔记 | 1 小时 |

# 🗺️ 学习路线

## Week 1：基础准备

- Python
- NumPy
- PyTorch
- Git
- Markdown

## Week 2：NLP 基础

- 文本预处理
- Tokenization
- Bag of Words
- TF-IDF
- N-Gram
- Word2Vec
- GloVe

## Week 3~4：Transformer

- Attention
- Self-Attention
- Multi-Head Attention
- Positional Encoding
- Encoder / Decoder
- LayerNorm
- Residual Connection

目标：能够从零实现一个 Mini Transformer。

## Week 5：BERT

- MLM
- NSP
- Fine-tuning
- 文本分类
- NER
- QA

## Week 6：GPT

- Decoder-only
- Causal Mask
- 自回归生成

## Week 7：现代 LLM

- LoRA
- PEFT
- QLoRA（了解）
- Instruction Tuning
- RLHF（理解思想）
- RAG（基础）

## Week 8：项目实战

- 新闻分类
- 情感分析
- 命名实体识别
- RAG 文档问答
- 论文智能分析系统
