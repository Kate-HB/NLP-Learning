# P3 演示与复习讲解稿

## 3 分钟演示

1. 输入“国产芯片公司发布新一代处理器”，展示分类标签、置信度和概率分布。
2. 输入一条跨领域文本，说明低置信度为何需要人工复核。
3. 提问“chunk 太大会有什么问题”，展示回答中的 `[1]` 与右侧来源。
4. 提问知识库外问题“今天北京天气如何”，展示低相关度拒答。

## 验收问题

### 分类模块输入输出是什么

输入是一个非空中文字符串；输出是预测标签、最高类别置信度和全部类别概率。服务隐藏 tokenizer、device 和模型细节。

### RAG 模块输入输出是什么

输入是问题与 Top-k；输出是基于检索上下文的回答、引用列表和原始检索结果。引用含文件名、chunk 编号和相似度。

### UI 如何展示不确定性

分类置信度低于阈值时警告；RAG 展示相似度和来源，检索分数过低时拒答。两种分数都不能解释为绝对正确率。

### 项目最大限制是什么

页面质量由 P1 模型和 P2 知识库决定。示例分类数据过小；RAG 也可能检索错或生成错。最有效的改进通常是高质量数据、离线评测集和错误分析，而非单纯美化 UI。

## 排错顺序

1. 分类不可用：检查 `p1-text-classification/outputs/bert-best/config.json`。
2. RAG 不可用：检查 `p2-rag-qa/outputs/index/vectors.npy` 和 `metadata.json`。
3. 回答无依据：先执行 `retrieve.py` 检查 Top-k，再检查生成器。
4. 页面打不开：确认当前环境已安装 Gradio，且终端端口未被占用。
