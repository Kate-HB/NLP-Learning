# P1 错误分析

## 分析步骤

1. 运行 `python evaluate.py` 生成 `outputs/evaluation/errors.csv`。
2. 按真实标签和预测标签分组，统计最常见的混淆方向。
3. 阅读错误文本，区分数据问题、信息不足、类别边界重叠和模型问题。
4. 每类补充相似难例后重新训练，比较 macro-F1，而非只看个别样本。

## 预期错误类型

| 类型 | 示例 | 原因 | 改进 |
|---|---|---|---|
| 跨领域 | “科技公司上市融资” | 同时包含科技和财经线索 | 明确标注规则，增加跨领域样本 |
| 信息不足 | “主队今日公布名单” | 缺少具体项目和上下文 | 增加正文或设置“其他”类 |
| 关键词误导 | “芯片股价格上涨” | “芯片”强烈指向科技，但主题是财经 | 加入相反标签的硬负例 |
| 小数据过拟合 | 训练句式相似 | 模型记住词而非语义 | 扩充来源，去重，检查泄漏 |

## 后续改进

- 使用真实新闻数据并保证 train/eval/test 按时间或来源隔离。
- 输出混淆矩阵和每类 precision、recall、F1。
- 对低置信度结果设置人工复核阈值。
- 对比 `bert-base-chinese` 与 `hfl/chinese-roberta-wwm-ext`。
