# 40 四种掩码辨析

> 一句话：Attention Mask 标记"有效 vs 填充"，Causal Mask 禁止看未来，MASK Token 是放进输入的特殊符号，Loss Mask 让无效位置不参与损失——四个都叫"掩码"，管的却是完全不同的四件事。

## 一、直观含义

四种"掩码"像四种不同的"禁止牌"：

- **Attention Mask**：贴着 PAD 位置挂"此位无效，请忽略"。
- **Causal Mask**：给 Decoder 挂"未来不可见"，保证生成时不能偷看答案。
- **MASK Token**：MLM 训练时把某些词"涂黑"（换成 `[MASK]`），让模型猜。
- **Loss Mask**：在算损失时给无效位置标"-100"之类，让它们不参与计分。

## 二、具体例子

- 批处理补 PAD 后：Attention Mask 把 PAD 位置标 0 → 注意力权重趋近 0。
- 生成 "NLP is"：Decoder 处理第 1 个位置时，Causal Mask 让它看不到第 2、3 个位置的 token。
- BERT 训练："我爱[MASK]猫"——`[MASK]` 是个真实 Token，模型要猜它本来是"看"还是"抱"。
- 训练 NER 时，PAD 和特殊 Token 位置的标签设为 -100，交叉熵自动跳过它们（见 [61-子词标签对齐](61-子词标签对齐.md)）。
- 训练 NER 时，PAD 和特殊 Token 位置的标签设为 -100，交叉熵自动跳过它们（见 [61-子词标签对齐](61-subword-label-alignment.md)）。

## 三、技术要点（严谨部分）

### 1. 四种掩码对照

| 名称 | 控制对象 | 一句话 |
|---|---|---|
| Attention Mask | 输入有效性 | 1=有效，0=PAD |
| Causal Mask | 注意力方向 | 位置 i 不能看 j>i |
| MASK Token | 输入内容 | MLM 里替换被遮盖词的符号 |
| Loss Mask | 损失位置 | 无效标签不计入损失 |

### 2. 掩码的实现机制

- 注意力层面的掩码（Attention / Causal）通常通过把禁止位置的注意力分数设为**极小值**实现。
- 极小值经过 Softmax 后权重趋近 0 → 该位置信息被忽略。

### 3. Decoder 里掩码如何组合

- Decoder 自注意力通常**同时组合**目标侧 Padding Mask 与 Causal Mask：既不能读取目标 Padding，也不能读取未来位置。
- Cross-Attention 使用**源序列的 Padding Mask**，避免 Decoder 关注 Encoder 输出中的源 Padding（见 [45-Decoder-的完整结构](45-Decoder-的完整结构.md)）。
- Cross-Attention 使用**源序列的 Padding Mask**，避免 Decoder 关注 Encoder 输出中的源 Padding（见 [45-Decoder-的完整结构](45-decoder-architecture.md)）。

### 4. 一个常被忽略的坑

> Padding 位置作为 Query 时仍可能产生隐藏状态，因此只做注意力屏蔽**并不等于自动排除训练误差**。

- 训练通常还要用 **Loss Mask**，让 Padding 等无效标签位置不参与损失计算。

### 5. "Masked" 的歧义提醒

- Decoder 的"Masked Self-Attention"指带因果掩码的自注意力——是**可见性限制**，不是把输入替换为 MASK Token。
- 千万别把"Masked Attention"和"MLM 的 MASK Token"当成一回事。

## 四、一句话总结

Attention Mask 管输入有效性、Causal Mask 管可见方向、MASK Token 管输入内容、Loss Mask 管损失位置——四个"掩码"四个分工，混了就会出错。
