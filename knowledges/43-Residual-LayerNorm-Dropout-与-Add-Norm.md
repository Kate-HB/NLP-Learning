# 43 Residual、LayerNorm、Dropout 与 Add & Norm

> 一句话：残差连接给深层网络一条"短路"、LayerNorm 稳定数值分布、Dropout 防过拟合；三者拼成的 Add & Norm 是每个子层外都包着的"稳定外壳"。

## 一、直观含义

- **残差连接**：把子层的输入和输出**直接相加**。像给瀑布修一条水管，让水（信息/梯度）不必爬过整段瀑布也能流过去——深层网络因此不"塌"。
- **LayerNorm**：把每个位置的特征"拉正"——均值归 0、方差归 1，再乘可学习缩放/平移。像给每个信号校准仪器。
- **Dropout**：训练时随机让一部分神经元"请假"（置零），逼模型不依赖固定组合——防过拟合。
- **Add & Norm**：残差相加 + LayerNorm 的合称，每个子层外面都套着它。

## 二、具体例子

```
x → 注意力 → ⊕（残差相加：x + attn(x)）→ LayerNorm → 输出
```

- 若注意力这层暂时学不到有用变换（输出 ≈ 0），残差让 `x + 0 = x`——信息原样通过，模型不会因此退化。
- LayerNorm 对 `x + attn(x)` 做标准化，防止数值越走越偏。

## 三、技术要点（严谨部分）

### 1. 残差连接（Residual Connection）

- 把**子层输入直接加到子层输出**上。
- 提供一条更短的信息和梯度通路，使深层网络更容易保留原始信息并稳定训练。
- 若子层暂时学不到有效变换，模型仍可通过残差路径传递输入。
- 也是缓解梯度消失（见 [25](25-反向传播-与链式法则.md)）的关键机制。
- 也是缓解梯度消失（见 [25](25-backpropagation-chain-rule.md)）的关键机制。

### 2. LayerNorm（层归一化）

- 对**单个样本某个位置**的隐藏维度进行标准化，再使用**可学习缩放和平移参数**调整。
- 减少不同层数值分布变化，改善训练稳定性。
- ⚠️ 与 **BatchNorm** 不同：BatchNorm 依赖 Batch 统计量；LayerNorm 主要在**特征维度**上工作，更适合可变长度序列。

### 3. Pre-Norm 与 Post-Norm

| 形式 | 顺序 | 说明 |
|---|---|---|
| Post-Norm | `LayerNorm(x + Sublayer(x))` | 原始 Transformer 形式 |
| Pre-Norm | `x + Sublayer(LayerNorm(x))` | 现代深层模型常用，梯度传播通常更稳定 |

- 它们使用相同组件，只是**归一化位置不同**。

### 4. Dropout

- 训练时随机把部分神经元输出**置零**，减少模型过度依赖固定特征组合，是正则化方法。
- 推理时通常**关闭** Dropout，并按训练规则保持期望值一致（如缩放存活单元）。

### 5. Add & Norm

- "残差相加 + 归一化"的简称。
- 注意力子层和 FFN 子层外通常都包有这套结构。

## 四、一句话总结

残差是"短路"、LayerNorm 是"校准"、Dropout 是"防依赖"；Add & Norm = 残差 + 归一化，是每个子层外标配的稳定外壳，让深层网络能真正"深下去"。
