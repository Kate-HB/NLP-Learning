# 24 梯度、梯度下降与学习率

> 一句话：梯度告诉模型"损失往哪个方向升得最快"，那往反方向走就能最快降下去；学习率决定每步走多大。


## 前置知识

- 先读 [23-标签-损失函数-与交叉熵](23-标签-损失函数-与交叉熵.md)。
- 先读 [23-标签-损失函数-与交叉熵](23-labels-loss-cross-entropy.md)。
- 只需要理解"导数 = 变化率"这一定义即可，不需要会算。

## 一、直观含义

把参数想象成山坡上的位置，损失是海拔。目标是走到"山谷最低处"：

- **梯度**：每个参数方向上的"坡度"。坡度向量指向**海拔上升最快的方向**。
- **梯度下降**：要下山，就往**坡度反方向**走，每次都走最陡的下坡路。
- **学习率**：每步迈多大。步子太大会跳过谷底甚至摔到对面山坡（震荡），太小则要磨蹭很久（收敛慢）。

## 二、具体例子

设 `L(x, y) = 2x + y`：

- `∂L/∂x = 2`（x 方向变化率），`∂L/∂y = 1`，梯度 `= (2, 1)`。
- 沿 x 走 1 步 → 上升 2；沿 y 走 1 步 → 上升 1；沿梯度方向走 1 步 → 上升约 `√(2²+1²) ≈ 2.24`——**任何方向都不如梯度方向上升快**。
- 更新公式：`w_new = w − 学习率 × 梯度`。减号 = 往反方向（下坡）走。

## 三、技术要点（严谨部分）

### 1. 梯度（Gradient）

- 各个参数**偏导数**组成的向量。
- 为什么是最速上升方向：移动方向与梯度的**内积 = 实际上升量**。而内积 `= |A|·|B|·cos(夹角)`，两方向一致时 `cos=1`、内积最大。所以梯度天然指向损失增长最快的方向。
- 要降低损失 → 沿反方向走。

### 2. 学习率（Learning Rate）

- 控制每次更新步长。
- 过大 → 震荡或发散；过小 → 收敛缓慢。
- 常用值：`5e-5` 这类小学习率在微调时很常见。

### 3. 梯度下降流程

```
repeat:
  1. 前向算损失 L
  2. 反向传播求梯度（见 25）
  3. w ← w − lr × gradient
```

### 4. 局部极小值与平原

- 神经网络的损失面很复杂，梯度下降可能停在"局部低谷"或缓坡，不保证找到全局最优——这是实践中的常态，靠更好的初始化、学习率调度等手段缓解。

## 四、一句话总结

梯度指向"损失上升最快"的方向，梯度下降就沿反方向走，学习率决定步长——这三个概念就是所有优化器（Adam 等）的地基。
