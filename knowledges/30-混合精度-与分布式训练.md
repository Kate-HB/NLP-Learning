# 30 混合精度与分布式训练

> 一句话：混合精度用低精度省显存提速、高精度保稳定；分布式训练用多设备分担计算，分为"切数据"的数据并行和"切模型"的模型并行。

## 一、直观含义

- **数值精度**：一个数用多少位存。位少 → 省显存、算得快，但数字更粗糙（可能溢出或丢精度）。
- **混合精度**：聪明的做法——矩阵计算用低精度（快、省），关键部分（如梯度累积、损失缩放）用高精度（稳）。像"写草稿用铅笔、记账用钢笔"。
- **分布式训练**：一台机器装不下或太慢，就请多台机器/多块卡一起干活：
  - **数据并行**：每人复制一份完整模型，各分一批数据算，最后把梯度平均。
  - **模型并行**：模型太大一张卡放不下，把模型切成几块，每张卡放一块。

## 二、具体例子

- BERT-base 约 1.1 亿参数，单张 GPU 能放下，用单卡 + 混合精度（如 FP16 主算 + FP32 主存）提速。
- 千亿参数 LLM：一张卡完全放不下 → 模型并行把层切开分布在多卡，再配合数据并行扩展吞吐。
- 深度学习框架的"自动混合精度"会托管大部分细节，但理解原理有助于排查精度相关的报错。

## 三、技术要点（严谨部分）

### 1. 数值精度（Numerical Precision）

- 描述数值用多少位表示。如 FP32（32 位）、FP16（16 位）、BF16。
- 位数越少：越省显存、运算越快，但**可表示范围和精确程度降低**。

### 2. 混合精度训练（Mixed-Precision Training）

- 同时使用较低精度和较高精度计算。
- 目标：在尽量保持训练稳定的同时，提高速度、降低显存占用。

### 3. 分布式训练（Distributed Training）

- 使用多个计算设备共同训练模型。

### 4. 数据并行（Data Parallelism）vs 模型并行（Model Parallelism）

| | 数据并行 | 模型并行 |
|---|---|---|
| 切什么 | 切**数据**（每个设备一份完整模型） | 切**模型**（不同部分放不同设备） |
| 同步 | 处理不同数据子集，同步梯度 | 前向/反向跨设备传递激活 |
| 适用 | 数据量大、单卡放得下模型 | 单个设备放不下完整模型 |
| 组合 | 两者可以组合使用 | 两者可以组合使用 |

### 5. 一个记忆点

> 数据并行切数据、模型并行切模型；可以先用数据并行，单卡放不下模型时再上模型并行。

## 四、一句话总结

混合精度在"省显存"和"保稳定"之间取巧，分布式在"多卡协作"上取巧；数据并行切数据、模型并行切模型，二者可组合。
