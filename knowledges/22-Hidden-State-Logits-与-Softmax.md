# 22 Hidden State、Logits 与 Softmax

> 一句话：Hidden State 是模型内部的"理解向量"，Logits 是未归一化的原始分数，Softmax 把 Logits 变成概率分布——三者是"理解 → 打分 → 出概率"的完整链条。

## 一、直观含义

- **Hidden State（隐藏状态）**：模型读到第 i 个词之后，"脑子里"对这个词的完整理解——一个向量。它叫"隐藏"，因为它不是最终答案，而是给下一层用的内部状态。
- **Logits**：模型对每个候选答案打的"原始分"。分数可以是负数，可以很大，**总和不必为 1**，甚至不为正。
- **Softmax**：把这一组原始分"拉成"总和为 1 的概率，分数越高概率越大。

## 二、具体例子

情感分类，3 个类别（负/中/正），模型输出 Logits：

```
Logits:  [-2.0,  0.5,  3.0]     ← 原始分数
Softmax: [ 0.006, 0.075, 0.919]  ← 概率分布，和为 1
Argmax:  2                      ← 概率最高的类别 = "正"
```

注意：Logits 里 3.0 和 -2.0 的差被放大成 0.919 vs 0.006 的概率差——Softmax 让"分高者赢家通吃"。

## 三、技术要点（严谨部分）

### 1. Hidden State（隐藏状态）

- 模型内部对输入的中间向量表示。
- 为什么叫"隐藏"：不是最终任务答案，而是后续层使用的内部状态。
- **上下文化**：同一个 Token 在不同句子里会得到不同向量，因为它融合了周围信息。
- **隐藏维度（Hidden Size）**：每个 Token 隐藏向量的长度（如 BERT 为 768）。
- 形状：`(batch, seq_len, hidden_size)`。

### 2. Logits

- 模型输出的**未经归一化的原始分数**。
- 可以为负数，不要求位于 0~1，不要求总和为 1。

### 3. Softmax

- 把一组 Logits 转成**总和为 1 的概率分布**。
- 某个 Logit 相对其他越大，其概率通常越高。
- ⚠️ Softmax 不改变同组分数的排序——最大值在变换前后仍是最大值。

### 4. 概率分布（Probability Distribution）

- 描述一组可能结果各自被赋予的概率。
- 离散分类中每项概率通常非负，全部结果概率之和为 1。

### 5. Argmax

- 选出最大值所在**位置**的操作，分类任务常用它选出分数最高的类别。

### 6. 完整链条

> Hidden State →（线性层投影）→ Logits →（Softmax）→ 概率 →（Argmax）→ 类别

## 四、一句话总结

Hidden State 是理解、Logits 是打分、Softmax 是转概率、Argmax 是拍板——从模型的内部表示到最终预测，就是这样一条链。
