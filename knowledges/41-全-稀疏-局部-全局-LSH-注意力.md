# 41 全、稀疏、局部、全局与 LSH 注意力

> 一句话：标准全注意力让每个 Query 看所有 Key，效果直接但成本随长度二次增长；稀疏、局部、全局、LSH 都是在"结构上省略部分连接"来降低长序列成本。


## 前置知识

- 先读 [38-注意力分数-权重-输出-与-Attention-Matrix](38-注意力分数-权重-输出-与-Attention-Matrix.md)。
- 先读 [38-注意力分数-权重-输出-与-Attention-Matrix](38-attention-scores-weights-outputs-matrix.md)。

## 一、直观含义

全注意力像"全班同学两两互相认识"——关系最全，但人越多开销越大（N² 份关系）。长文本时开销爆炸，于是出现各种"少算一点"的办法：

- **局部注意力**：只看左右邻居（像只跟前后桌说话）。单层视野窄，但多叠几层，信息能一层层传远。
- **全局注意力**：选少数几个"班干部"（Global Token），让他们跟全班都有联系，其他人通过他们间接联系。
- **稀疏注意力**：统称"故意跳过大部分连接"的做法。
- **LSH 注意力**：给每个词发个"哈希桶编号"，只跟同桶（长相相似）的词算注意力——像按身高排队，只跟身高差不多的交流。

## 二、具体例子

- **Longformer**：每个词看附近窗口 + 少数全局 Token——长文档既能高效又能传全局信息。
- **Reformer**：用局部敏感哈希把 Query 和 Key 分桶，只在桶内算注意力，大幅降低长序列成本。
- **滑动窗口（某类 LLM 的做法）**：每个位置只看固定窗口内的邻居，配合层数堆叠扩大感受野。

## 三、技术要点（严谨部分）

### 1. 全注意力（Full Attention）

- 每个 Query 与所有可见 Key 计算关系。
- 表达能力直接，但注意力矩阵随序列长度**二次增长**。

### 2. 稀疏注意力（Sparse Attention）

- 只计算**预先选择**的一部分位置关系，以降低长序列成本。
- ⚠️ 它不是"把注意力权重训练得很小"，而是**在结构上省略部分连接**——根本不计算那些连接。

### 3. 局部注意力（Local Attention）

- 每个 Token 主要关注**附近窗口**。
- 单层视野有限，但多层堆叠后信息可以逐层传播到更远位置。

### 4. 全局注意力（Global Attention）

- 让少数选定 Token 与**全序列**交互。
- Longformer = 局部窗口 + 少量全局 Token，长文档既保留局部效率，又能传播全局信息。

### 5. LSH 注意力（局部敏感哈希注意力）

- **哈希（Hashing）**：把对象映射到较小标识空间的方法。
- **局部敏感哈希（LSH）**：特别希望相似对象有较高概率落入**同一桶**。
- LSH Attention：把可能相似的 Query 和 Key 分到相近桶中，**只在候选桶内**计算注意力。
- Reformer 使用这类思想减少长序列计算。

### 6. 记住主线

> 全注意力是"标准答案"，但二次成本让它难以上长序列；所有变体都在"省连接"上做文章，用一点表达力的代价换长度。

## 四、一句话总结

全注意力看全部（贵）、局部看邻居（省但窄）、全局选代表（传得远）、LSH 按相似分桶（只算近的）——四类方案在"表达力"和"长序列成本"之间做取舍。
