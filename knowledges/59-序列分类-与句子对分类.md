# 59 序列分类与句子对分类

> 一句话：序列分类给整段文本判一个或多个标签，句子对分类判断两段文本的关系；两者都用"整段表示 + 分类 Head"完成。


## 前置知识

- 先读 [22-Hidden-State-Logits-与-Softmax](22-Hidden-State-Logits-与-Softmax.md)、[48-Backbone-Task-Head-与-Weight-Tying](48-Backbone-Task-Head-与-Weight-Tying.md)。
- 先读 [22-Hidden-State-Logits-与-Softmax](22-hidden-state-logits-softmax.md)、[48-Backbone-Task-Head-与-Weight-Tying](48-backbone-task-head-weight-tying.md)。

## 一、直观含义

- **序列分类**：给整段输入"盖一个章"——这段是正面/负面，这条新闻是科技/体育。
- **句子对分类**：给两段文本的关系"下判断"——这两句是不是一个意思？这个前提能推出这个结论吗？

## 二、具体例子

- 情感分类："这家店的排骨特别咸" → 负面。
- 多标签：一篇新闻同时被标为"科技""国际"。
- 句子对："苹果发布了新系统" vs "一家公司发布了新系统" → 语义等价。
- 蕴含："今天是晴天" 蕴含 "今天没有下雨"。

## 三、技术要点（严谨部分）

### 1. 序列分类（Sequence Classification）

- 为整个输入预测**一个或多个标签**。
- 流程：产生整段文本的表示 → 分类 Head 输出各类别 Logits。
- 整段表示可以来自 **CLS Token、平均池化或其他聚合方式**。

### 2. 单标签 vs 多标签

- **单标签分类（Single-label）**：互斥类别中只能选一个（正/负/中性）。
- **多标签分类（Multi-label）**：多个标签可同时成立（一篇文章既是科技又是国际）。
- 两者的输出解释、损失和阈值策略不同（多标签常按 Sigmoid 逐类独立判，而不是 Softmax 选一）。

### 3. 池化（Pooling）

- 把**可变长度的 Token 表示**聚合为**固定长度向量**。
- 常见方式：取 CLS、平均池化、最大池化。
- 用途不只在分类——句向量也要用池化（见 [64-上下文嵌入-句子嵌入-与对比学习](64-上下文嵌入-句子嵌入-与对比学习.md)）。
- 用途不只在分类——句向量也要用池化（见 [64-上下文嵌入-句子嵌入-与对比学习](64-contextual-sentence-embedding-contrastive.md)）。

### 4. 句子对分类（Sentence Pair Classification）

- 判断两段文本之间的关系，例如：语义是否等价、前提是否蕴含假设。
- **蕴含（Entailment）**：在前提为真时，假设能够由前提推出；**不同于两句话字面相同**。
- 典型数据集：GLUE/MRPC（句对等价）、MNLI（蕴含）。

### 5. 句子对 ≠ Batch

> 句子对是**一个样本内部的两个序列**；Batch 是**多个独立样本的集合**。

- 一个样本 = `(A, B)` 两句，是"一对"。
- Batch 里可以装很多个这样的句子对样本。

## 四、一句话总结

序列分类给整段盖章、句子对分类给两段关系下判断；两者都靠"整段/整对的表示 + 分类 Head"，区别只在输入是"一段"还是"一对"。
