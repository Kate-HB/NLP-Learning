# 70 Macro、Micro、Weighted 与 Baseline

> 一句话：多分类指标怎么把"每个类别的分数"汇总成一个数，有三种方式——Macro 等权平均（偏袒小类）、Micro 先合计数再算（偏向大类）、Weighted 按样本数加权；Baseline 是拿来对照的"及格线"。

## 一、直观含义

一个模型在 3 个类别上各有 Precision/Recall。怎么报"一个总 F1"？三套算法，回答三个不同的问题：

- **Macro**：三个类别的分**平等平均**——每类一票，小类别也有话语权。
- **Micro**：先把所有类别的 TP/FP/FN **加起来**，再算一个总指标——大类别数据多、影响自然大。
- **Weighted**：按每类的**真实样本数**加权平均——介于两者之间，更贴近"总体表现"。

**Baseline（基线）**：一个"够简单"的对照方法（如取前三句做摘要、全猜多数类）。它回答一个关键问题："你的复杂方法到底有没有真的变好？"

## 二、具体例子

三类 F1：类A=0.9（1000 样本）、类B=0.8（100 样本）、类C=0.5（10 样本）：

- Macro F1 = (0.9+0.8+0.5)/3 ≈ 0.733——小类 C 拖了后腿，被平等计算。
- Weighted F1 ≈ (0.9×1000 + 0.8×100 + 0.5×10)/1110 ≈ 0.887——被大样本的 A 主导。
- 报指标时必须**说清用的是哪种**，否则没法比。

## 三、技术要点（严谨部分）

### 1. 多分类的通用做法

- 把每个类别轮流视为"正类"、其余类别视为"负类"。
- 各自算出 Precision/Recall/F1 后，再用下面的方式汇总。

### 2. 三种平均方式

| 方式 | 做法 | 偏向 |
|---|---|---|
| Macro Average | 先分别算每类指标，再**等权平均** | 更关注小类别 |
| Micro Average | 先**汇总所有类别的预测计数**，再计算指标 | 更受大类别影响 |
| Weighted Average | 按各类别**真实样本数量加权**平均 | 贴近总体样本分布 |

### 3. ⚠️ 报告必须说明平均方式

- 同名 F1 若平均方式不同，**含义和数值都可能不同**。
- 比较模型时，必须用同一种平均方式。

### 4. Baseline（基线）

- 用于比较的简单方法或已有模型。
- 回答："复杂方法是否真的带来提升？"
- **没有基线，单独一个分数很难判断价值**。
- 常见基线：全猜多数类、简单规则（如摘要的 Lead-3 取前三句）、上一个已有模型。

### 5. 指标与 Loss 的关系（回顾）

- Metric 用于评价、Loss 用于训练——两者可能相关但**不能互相替代**（见 [23-标签-损失函数-与交叉熵](23-标签-损失函数-与交叉熵.md)）。
- Metric 用于评价、Loss 用于训练——两者可能相关但**不能互相替代**（见 [23-标签-损失函数-与交叉熵](23-labels-loss-cross-entropy.md)）。

## 四、一句话总结

Macro 每类一票、Micro 先总数再算、Weighted 按样本加权——报 F1 必须注明平均方式；基线是"及格线"，没有它分数就失去了参照。
