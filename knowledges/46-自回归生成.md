# 46 自回归生成

> 一句话：自回归生成就是"每次根据已有前文预测一个新 Token，把新 Token 加回前文再预测下一个"；整段输出概率 = 每一步条件概率的连乘。


## 前置知识

- 先读 [45-Decoder-的完整结构](45-Decoder-的完整结构.md)。
- 先读 [45-Decoder-的完整结构](45-decoder-architecture.md)。
- "条件概率"用直观理解即可。

## 一、直观含义

像"接龙游戏"：先有开头，每次只往外蹦一个字，蹦出来的字又变成下一步的开头。

- 已生成："我爱"
- 预测下一个字：模型从词表里给每个候选打分 → 选出"自"
- 现在："我爱自"
- 再预测下一个字：→ "然"
- …一直到生成了结束符或达到上限。

## 二、具体例子

生成 "我爱自然语言处理"：

```
输入:  <s>
输出: 我
输入:  <s> 我
输出: 爱
输入:  <s> 我 爱
输出: 自
...
输入:  <s> 我 爱 自 然 语 言 处 理
输出: <eos>（停止）
```

## 三、技术要点（严谨部分）

### 1. 定义

- **自回归生成（Autoregressive Generation）**：每次根据已有前文预测一个新 Token，再把新 Token 加回输入继续预测。
- "自回归"（auto-regressive）= 用自己的输出当输入，一步步推进。

### 2. 条件概率分解

- 整段输出的概率由每一步"在已有前文条件下生成当前 Token"的概率**连乘**得到：

```
P(w₁ w₂ … wₙ) = P(w₁) · P(w₂|w₁) · P(w₃|w₁w₂) · … · P(wₙ|w₁…wₙ₋₁)
```

- 每一步的概率来自 Decoder 输出的 LM Logits（Softmax 后，见 [22-Hidden-State-Logits-与-Softmax](22-Hidden-State-Logits-与-Softmax.md)）。
- 每一步的概率来自 Decoder 输出的 LM Logits（Softmax 后，见 [22-Hidden-State-Logits-与-Softmax](22-hidden-state-logits-softmax.md)）。

### 3. 误差累积风险

- 自回归生成具有**误差累积**风险：某一步生成错误后，后续步骤会以**错误内容作为真实上下文**继续生成——一步错、步步错。
- 这也是训练用 Teacher Forcing 造成的"暴露偏差"在推理时的体现（见 [51-Seq2Seq-Teacher-Forcing-与目标右移](51-Seq2Seq-Teacher-Forcing-与目标右移.md)）。
- 这也是训练用 Teacher Forcing 造成的"暴露偏差"在推理时的体现（见 [51-Seq2Seq-Teacher-Forcing-与目标右移](51-seq2seq-teacher-forcing-label-shift.md)）。

### 4. 训练 vs 推理

- **训练**：完整目标已知，所有位置的输入可提前构造，可**并行**（见 [54-训练为什么并行-生成为什么串行](54-训练为什么并行-生成为什么串行.md)）。
- **训练**：完整目标已知，所有位置的输入可提前构造，可**并行**（见 [54-训练为什么并行-生成为什么串行](54-why-train-parallel-generate-serial.md)）。
- **推理**：下一步依赖上一步实际生成的 Token，**通常串行**。

### 5. 停止条件

- 生成到 EOS Token，或达到最大新 Token 数，或出现指定终止串时停止（见 [58-解码策略-Sampling-Temperature-Top-k-Top-p](58-解码策略-Sampling-Temperature-Top-k-Top-p.md)）。
- 生成到 EOS Token，或达到最大新 Token 数，或出现指定终止串时停止（见 [58-解码策略-Sampling-Temperature-Top-k-Top-p](58-decoding-sampling-temperature-topk-topp.md)）。

## 四、一句话总结

自回归 = "已有前文 → 预测下一个 → 追加 → 再预测"，整段概率是条件概率连乘；它简单可靠，但一步错会步步错，且推理必须一步步来。
