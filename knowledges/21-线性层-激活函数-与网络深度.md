# 21 线性层、激活函数与网络深度

> 一句话：线性层改变维度、激活函数注入非线性、深度让网络能学习越来越抽象的特征——三者拼起来才叫"深度神经网络"。

## 一、直观含义

- **线性层**：一台"变形机"，把 768 维的向量变成别的维度（比如 2 维），本质是 `W·x + b`。
- **激活函数**：一台"开关机"，给网络加入非线性。**没有它，叠再多层也只是一层**——因为线性套线性还是线性。
- **深度**：把这些层叠多高。层越多，越能学"从笔画→字母→单词→句子含义"这种层层抽象。

## 二、具体例子

- BERT 里 FFN 把隐藏维度从 768 扩到 3072，激活，再压回 768。
- 分类任务最后接一个线性层：768 → 3（三类别），输出 3 个 Logits。
- 激活函数 ReLU：`ReLU(-3) = 0`，`ReLU(5) = 5`——负数清零、正数保留。

## 三、技术要点（严谨部分）

### 1. 线性层（Linear Layer）

- 对输入执行矩阵乘法并加偏置：`y = W·x + b`。
- 用途：改变表示维度，或产生任务分数。

### 2. 激活函数（Activation Function）

- 为网络加入**非线性**。
- 为什么必须要有：若所有层都只是线性变换，无论叠多少层都等价于一层线性变换，难以学习复杂关系。

### 3. 常见激活函数

- **ReLU（修正线性单元）**：负数变零、正数不变。经典、快。
- **GELU**：以更平滑的方式控制输入通过程度，常用于 BERT 和许多 Transformer。

### 4. 网络深度（Depth）

- 通常指模型堆叠的**层数**。
- 更深的层可以逐步形成更抽象的表示，但训练和计算成本也更高。

### 5. 为什么"深"有用

浅层常捕捉局部形式（相邻字、短语），深层捕捉更抽象的语义关系。但注意：这种"分工"是训练自然涌现的，**不是人工硬编码的**。

## 四、一句话总结

线性层负责变形、激活函数负责"打弯"、深度负责堆高——三者组合，神经网络才能从简单输入逐层学到抽象语义。
