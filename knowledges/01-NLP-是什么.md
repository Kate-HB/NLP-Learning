# 01 NLP 是什么

> 一句话：NLP（Natural Language Processing，自然语言处理）是研究如何让计算机处理、理解和生成人类语言的领域。

## 一、直观含义

想象让一台电脑学会"读文章、听人说话、回答提问、写一段话"。这就是 NLP 在做的事。"自然语言"指人类日常使用的语言（中文、英语、法语等），用来区别于按严格规则设计的编程语言。

关键认知：**NLP 不等于"让机器真正像人一样理解语言"**。当前主流做法是让模型从海量数据里学习语言的**形式、语义关系和任务规律**，再根据输入算出最可能的输出。模型看起来很聪明，但这种能力受三样东西限制：训练数据、模型结构、上下文长度与任务目标。

## 二、具体例子

- "苹果发布了新系统"：这里的"苹果"是公司而不是水果。判断它指公司，需要看"发布""系统"这些上下文——这属于语义消歧。
- "这家公司去年发布了新系统"：如果前文出现过"这家公司"，还要能把"这家"和"苹果"联系起来——这属于篇章指代。

## 三、技术要点（严谨部分）

### 1. NLP 的四个核心问题

1. **表示**：怎样把文字变成可计算的数字。
2. **理解**：怎样判断文本的类别、实体、关系、意图和语义。
3. **生成**：怎样根据已有文本产生后续文本或新的目标文本。
4. **检索与应用**：怎样从大量文本中找相关知识，并把模型能力组合成可用系统。

### 2. NLU 与 NLG

- **自然语言理解（NLU）**：偏向识别意义、意图、实体和关系的一组任务。
- **自然语言生成（NLG）**：根据条件产生连贯语言的一组任务。

注意：它们只是方便理解的任务分区，**不是绝对分开的技术体系**。生成好文本也需要理解输入；理解类模型也通过"预测语言"的目标学习表示。

### 3. 语言的多个层次

一个句子同时包含多个层次的信息：

| 层次 | 含义 | 例子 |
|---|---|---|
| 字符（Character） | 书写系统的基本符号 | 汉字、字母、标点 |
| 词（Word） | 有独立意义或语法功能的单位 | "苹果""发布" |
| 词法（Morphology） | 词的内部构成 | 词根、前缀、后缀、词形变化 |
| 句法（Syntax） | 词如何组成短语和句子 | 主谓宾结构 |
| 语义（Semantics） | 字面意义及词句间的意义关系 | "苹果"指公司还是水果 |
| 语用（Pragmatics） | 在具体情境中的实际含义 | 说话者目的、常识、暗示 |
| 篇章（Discourse） | 多句如何组成连贯文本 | 指代、主题延续、逻辑关系 |

## 四、一句话总结

NLP 是让计算机处理、理解和生成人类语言的研究领域；它通过数据和模型来工作，核心是"表示 → 理解 → 生成 → 检索应用"四件事，而**不等于**真正的人类理解。
