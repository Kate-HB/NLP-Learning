# 74 Transformer 信息流的统一理解

> 一句话：从底层看，Transformer 是一条"文本 → ID → 向量 → 注意力+FFN 多层加工 → 任务 Head → 训练/推理"的流水线；从高层看，BERT、GPT、T5、NER、RAG 都是这条流水线上换零件的产物。


## 前置知识

- 全部系列已读完。本文是收官之作：把零散知识点串成一条线。

## 一、直观含义

学了一堆概念，最后要问：**它们是怎么连起来的？** 答案是一条流水线和四个"可换零件"。

- 流水线：文本进来 → 数字 → 向量 → 反复"词间交换 + 词内变换" → 输出表示 → 接任务头。
- 四个可换零件：**输入怎样组织、哪些位置可见、训练目标是什么、输出怎样解释**。
- 任何新模型/新任务，本质都是在这四个位置上换配置。

## 二、底层数据流（12 步）

1. Tokenizer 把语言切成离散 Token，并映射为 Token ID。
2. Token Embedding 把 Token ID 变成连续向量，位置表示加入顺序信息。
3. 注意力让每个位置从其他允许位置**读取相关信息**。
4. 多头机制让模型在多个表示子空间**并行建立关系**。
5. FFN 对每个位置的聚合信息做**非线性变换**。
6. 残差连接和 LayerNorm 改善深层网络的优化稳定性，Dropout 降低过拟合风险；它们**不能保证训练必然成功**。
7. 多层 Block 反复执行信息交换与特征变换，形成**上下文化隐藏状态**。
8. 任务 Head 把隐藏状态转成类别、实体标签、词表 Logits 或答案边界。
9. 训练阶段先按任务构造标签：
   - MLM：只在被选中的遮盖位置计算损失。
   - CLM：用位置 i 的 Logits 对齐位置 i+1 的 Token。
   - Seq2Seq：使用右移目标作为 Decoder 输入。
   - Padding 和无效位置由**损失掩码**排除。
10. 模型使用交叉熵等损失衡量预测与标签差距，通过反向传播计算梯度，再由优化器更新参数。
11. Encoder 推理根据任务分成三条常见输出支路：**池化后整段分类、逐 Token 分类、从起止分数选答案跨度**。
12. 生成推理从 LM Logits 选择 Token ID，追加到序列，重新形成下一步输入并循环，直到满足停止条件。

## 三、高层统一理解

> BERT、GPT、T5、NER、翻译、摘要、问答和 RAG 并不是彼此孤立的知识：

- **BERT** = Encoder + 双向上下文 + MLM。
- **GPT** = 因果 Decoder + 自回归生成目标（CLM）。
- **T5** = 把任务统一成文本到文本的 Encoder-Decoder 生成。
- **NER** = Token 隐藏状态上增加 Token 分类 Head。
- **翻译和摘要** = 源序列条件下的 Decoder 生成。
- **抽取式 QA** = 在输入隐藏状态上寻找答案起止位置。
- **Sentence Embedding** = 把 Token 隐藏状态聚合成可比较的句子/段落向量。
- **语义搜索** = 用向量距离检索文本。
- **RAG** = 把检索结果重新放入生成模型的上下文，组合外部知识与语言生成。

## 四、四个可换零件（总结论）

| 可换零件 | 问题 | 对应概念 |
|---|---|---|
| 输入怎样组织 | 文本怎么变向量、加什么位置/结构 | Tokenizer、Embedding、位置编码、特殊 Token |
| 哪些位置可见 | 能不能看未来、能不能看两侧 | Causal Mask、双向、Cross-Attention |
| 训练目标是什么 | 模型被要求学会什么 | MLM、CLM、Seq2Seq、NSP |
| 输出怎样解释 | 隐藏状态怎么变任务结果 | Task Head、解码策略、池化 |

## 五、一句话总结

Transformer = 一条"文本 → 向量 → 交换+变换 → 任务头"的流水线；所有模型和任务都只是换四个零件——怎么组织输入、哪些位置可见、学什么目标、输出怎么解释。掌握这一条主线，新模型就不再是新知识，而是旧零件的重新排列。
