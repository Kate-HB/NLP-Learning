# 08 语料、样本、序列与上下文

> 一句话：这一篇给"数据长什么样"正名——语料是一堆材料，样本是单位，序列是顺序符号，上下文是模型预测时能用的信息。

## 一、直观含义

这组词解决"我们拿什么喂给模型"的问题：

- **语料** = 一座图书馆（一堆语言材料）。
- **文档** = 图书馆里的一本书（一段相对完整的文本）。
- **样本** = 每次考试要处理的一道题（一次训练/评估的单位）。
- **序列** = 有顺序排列的符号串（在 NLP 里通常指 Token 序列）。
- **上下文** = 做这道题时允许翻看的资料（句子其他部分、提示词、历史对话、检索到的文档）。

## 二、具体例子

- 训练情感分类时：语料是 4000 条评论；每一条评论是一个样本；每条评论分词后是一个 Token 序列。
- 训练翻译时：一个样本是"一对句子"（源语言 + 目标语言）。
- 训练问答时：一个样本是"问题 + 上下文段落 + 答案"。
- 聊天时：上下文 = 你之前说的几轮话 + 系统提示。

## 三、技术要点（严谨部分）

- **语料（Corpus）**：用于训练、验证或研究的一组语言材料。
- **文档（Document）**：一段相对完整的文本单位，如一篇文章、一条评论、一个网页。
- **样本（Example / Sample）**：一次训练或评估处理的基本数据单位。
  - 一个样本可能是一句话、一对句子、一个问题加上下文、或一篇文章加摘要——**不是固定等于一句话**。
- **序列（Sequence）**：按顺序排列的符号集合，在 NLP 中通常指 Token 序列。
- **上下文（Context）**：模型在当前预测时可利用的信息。
  - 它可以是一句话的其他部分，也可以是提示词、历史对话或检索到的文档。
  - ⚠️ 注意：上下文不是永久记忆。模型只"看到"这一次输入里给的上下文（详见 [56-KV-Cache-与-Context-Window](56-KV-Cache-与-Context-Window.md)）。
  - ⚠️ 注意：上下文不是永久记忆。模型只"看到"这一次输入里给的上下文（详见 [56-KV-Cache-与-Context-Window](56-kv-cache-context-window.md)）。

## 四、一句话总结

语料是全部材料，文档是其中一段，样本是一次处理的题目，序列是题目的符号形式，上下文是做题时能用的资料；这五个词构成讨论一切 NLP 数据的共同语言。
