# 68 Transformer 处理图像和音频

> 一句话：Transformer 的输入本质是"向量序列"，不限于文字——图像切 Patch、音频切频谱帧，都能变成序列喂给注意力。


## 前置知识

- 先读 [31-Transformer-为什么出现](31-Transformer-为什么出现.md)。
- 先读 [31-Transformer-为什么出现](31-why-transformer.md)。
- 只需要"序列 = 有顺序的向量"这个概念即可。

## 一、直观含义

注意力做的事就是"在一串元素之间建立关系"——它不在乎这些元素是字、图像小块还是声音片段。只要把任何模态**切成有顺序的小块、变成向量**，就能交给同一个 Transformer。

- 文字：Token → 向量。
- 图像：切成方块（Patch）→ 每个 Patch 映射成向量。
- 音频：切成时间/频率格子（频谱）→ 序列。

## 二、具体例子

- **ViT（视觉 Transformer）**：把一张图切成 16×16 的 Patch，每个 Patch 变成一个向量，像处理 Token 一样丢给 Encoder。
- **Whisper**：把音频先转成频谱特征序列，再用 Encoder-Decoder 生成文字。

## 三、技术要点（严谨部分）

### 1. 核心思想

> Transformer 的本质是**序列关系建模**；文本 Token、图像 Patch 和音频帧只是不同输入单位。

- 注意力只要求：输入是**一组有顺序的向量**。
- 因此只要把其他模态**转换为序列**，注意力就能在这些序列元素之间建立关系。

### 2. 模态（Modality）

- 信息的表现形式：文本、图像、音频、视频等。

### 3. 视觉 Transformer（ViT）

- 把图像切成多个**固定大小**的 Patch。
- 把每个 Patch **映射为向量**，再像处理 Token 一样交给 Encoder。
- **图像块（Patch）**：图像中的矩形局部区域，相当于视觉序列的基本单位。

### 4. 语音模型（如 Whisper）

- 先把音频转换为**频谱特征序列**，再由 Encoder-Decoder 生成文字。
- **频谱（Spectrogram）**：描述声音能量如何随**时间和频率**变化，是音频波形的**时频表示**。

### 5. 一个推论

- 理解了"输入是序列"这一层，就明白为什么多模态模型能共用同一套 Transformer 骨架——只要把不同模态都"切成序列、映射成向量"，剩下的注意力、FFN 全都通用。

## 四、一句话总结

Transformer 只认"有序的向量序列"，不认文字；图像切 Patch、音频切频谱帧，都能改造成它认识的样子——这就是 ViT、Whisper 等多模态模型的基础。
