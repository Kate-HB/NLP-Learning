## 一、十组辨析

### 1. Training 与 Inference

- **Training**：有正确答案，计算损失并**更新参数**。
- **Inference**：没有标签监督，**不更新参数**，只产生预测。
- 详见 [54](54-训练为什么并行-生成为什么串行.md)、[55](55-推理-Prefill-与-Decoding.md)。
- 详见 [54](54-why-train-parallel-generate-serial.md)、[55](55-inference-prefill-decoding.md)。

### 2. Teacher Forcing 与 Autoregressive Generation

- **Teacher Forcing**：**训练**时使用**真实目标前文**。
- **Autoregressive Generation**：**推理**时使用**模型自己已生成的前文**。
- 前者是训练技巧、后者是推理行为；两者之间的落差就是暴露偏差（详见 [51](51-Seq2Seq-Teacher-Forcing-与目标右移.md)、[46](46-自回归生成.md)）。
- 前者是训练技巧、后者是推理行为；两者之间的落差就是暴露偏差（详见 [51](51-seq2seq-teacher-forcing-label-shift.md)、[46](46-autoregressive-generation.md)）。

### 3. Sequence Classification 与 Token Classification

- **序列分类**：对整段输入输出一个或多个标签（"一句话一个结论"）。
- **Token 分类**：对每个 Token 输出标签（"每个词一个结论"）。
- 详见 [59](59-序列分类-与句子对分类.md)、[60](60-Token-分类-NER-POS-Chunking-与-IOB2.md)。
- 详见 [59](59-sequence-and-pair-classification.md)、[60](60-token-classification-ner-pos-chunking-iob2.md)。

### 4. Extractive 与 Generative

- **Extractive**：从原输入中**选择**片段（答案一定是原文里有的）。
- **Generative**：**生成**原文中没有连续出现的新表达（更灵活，也更需事实约束）。
- 详见 [62](62-机器翻译-与文本摘要.md)、[63](63-抽取式问答-生成式问答-与幻觉.md)。
- 详见 [62](62-machine-translation-summarization.md)、[63](63-extractive-generative-qa-hallucination.md)。

### 5. Keyword Search 与 Semantic Search

- **Keyword Search**：匹配**字面词语**。
- **Semantic Search**：比较**向量表达的含义**。
- ⚠️ 语义搜索**不是永远更好**：精确编号、专名和固定术语有时更适合关键词匹配。
- 详见 [65](65-向量空间-相似度度量-与检索.md)。
- 详见 [65](65-vector-space-similarity-retrieval.md)。

### 6. Model Parameter 与 Hyperparameter

- **Parameter**：由**训练**学习。
- **Hyperparameter**：由**训练前设定**或通过验证选择。
- 详见 [20](20-参数-权重-偏置-与超参数.md)。
- 详见 [20](20-parameters-weights-bias-hyperparameters.md)。

### 7. Loss 与 Metric

- **Loss**：用于反向传播的**可微优化目标**。
- **Metric**：用于评价实际表现的**指标**。
- 两者可能相关，但**不能互相替代**（训练指标降不代表业务表现升）。
- 详见 [23](23-标签-损失函数-与交叉熵.md)。
- 详见 [23](23-labels-loss-cross-entropy.md)。

### 8. Context Window 与 Memory

- **Context Window**：本次推理**可见**的 Token 范围。
- **Memory**：系统额外保存、**未来重新提供**的信息。
- 模型不会因为一次读过内容就永久记住，除非**参数被训练更新**或**外部系统再次提供**。
- 详见 [56](56-KV-Cache-与-Context-Window.md)。
- 详见 [56](56-kv-cache-context-window.md)。

### 9. Attention Head 与 Task Head

- **Attention Head**：多头注意力**内部**的一条关系计算通道（Q、K、V 一组）。
- **Task Head**：骨干网络**之后**，把隐藏状态映射成分类/标签/答案/词表输出。
- 前者在 Block 内部、后者面向任务（详见 [39](39-Self-Attention-与-Multi-Head-Attention.md)、[48](48-Backbone-Task-Head-与-Weight-Tying.md)）。
- 前者在 Block 内部、后者面向任务（详见 [39](39-self-attention-multi-head-attention.md)、[48](48-backbone-task-head-weight-tying.md)）。

### 10. Tokenizer Decoding、Transformer Decoder 与 Generation Decoding

| 中文都叫"解码" | 对象 | 含义 |
|---|---|---|
| Tokenizer Decoding | Token ID | 还原成文本 |
| Transformer Decoder | 网络架构 | 因果自注意力等组成的结构 |
| Generation Decoding | 概率分布 | 依策略选择下一个 Token |

- 三者对象分别是"ID、神经网络表示、概率分布"（详见 [55](55-推理-Prefill-与-Decoding.md)）。
- 三者对象分别是"ID、神经网络表示、概率分布"（详见 [55](55-inference-prefill-decoding.md)）。

## 三、一句话总结

训练 vs 推理看"更不更参数"，教师强制 vs 自回归看"真前文还是自己前文"，窗口 vs 记忆看"这次可见还是将来再给"，三种解码看"对象是 ID、网络还是概率"——边界清楚了就不混。
