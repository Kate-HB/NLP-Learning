# 19 标量、向量、矩阵、张量与点积

> 一句话：神经网络里一切都是数字的"多维容器"——标量是单个数，向量是一串数，矩阵是二维表，张量是任意维容器；点积和矩阵乘法是神经网络最核心的两种运算。

## 一、直观含义

- **标量**：一个数，比如温度 25。
- **向量**：一串排好序的数，比如一个词的 768 维特征，可以想成 768 维空间里的一个点。
- **矩阵**：一张数表（行 × 列），比如 3 个词的向量摞在一起 → 3×768 的矩阵。
- **张量**：更一般化，就是"多维数组"——上面的都能叫张量，只是维度多少的区别。
- **点积**：两个等长向量"对应相乘再全加起来"，得到一个数。它衡量两个向量"方向合不合"。
- **矩阵乘法**：一堆点积批量执行，是线性层和注意力的核心运算。

## 二、具体例子

- 向量：`[3, 4]`，长度（范数）为 5。
- 点积：`[1, 2, 3] · [4, 5, 6] = 1×4 + 2×5 + 3×6 = 32`。
- 矩阵乘法：形状 `(2,3) × (3,4) = (2,4)`——内层维度 3 必须相等，结果取外层 2、4。
- 转置：把 `(3,2)` 变 `(2,3)`，行变列、列变行。

## 三、技术要点（严谨部分）

### 1. 标量、向量、矩阵、张量

- **标量（Scalar）**：单个数值。
- **向量（Vector）**：一维有序数值集合。可表示一个 Token、句子或样本的特征。
- **矩阵（Matrix）**：二维数值数组，可表示一组向量或线性变换。
- **张量（Tensor）**：更一般的多维数值数组。
  - 一个文本 Batch：`批次数 × 序列长度` 的 ID 张量。
  - 隐藏状态：`批次数 × 序列长度 × 隐藏维度` 的三维张量。

### 2. 形状（Shape）与维度（Dimension）

- **形状**：张量每个维度的大小，如 `(4, 768)`。
- ⚠️ **维度**一词有歧义：既可指"张量的轴数"（2 维 = 平面），也可指"向量有多少个数"（768 维）。读上下文时要区分。

### 3. 特征（Feature）

- 模型用于描述输入的可计算属性。
- 在深度学习中，许多特征不是人工命名的，而是由隐藏向量的多个维度共同学习出来的。

### 4. 点积（Dot Product）

- 两个等长向量对应元素相乘后求和。
- 数值同时受**方向**和**长度**影响。
- 只有在先把向量归一化之后，点积才只反映方向，等同于**余弦相似度**。
- 是注意力相关性分数的基础（见 [37-Scaled-Dot-Product-Attention](37-Scaled-Dot-Product-Attention.md)）。
- 是注意力相关性分数的基础（见 [37-Scaled-Dot-Product-Attention](37-scaled-dot-product-attention.md)）。

### 5. 矩阵乘法与转置

- **矩阵乘法**：按行与列的对应乘积求和，把一组向量映射到新的表示空间。
- **转置（Transpose）**：交换矩阵的行与列，常用上标 T 表示。注意力里的 Kᵀ 使所有 Query 能同时与所有 Key 做点积。
- **线性变换**：用矩阵乘法把输入向量投影到新坐标空间。加入偏置后严格说是仿射变换，但神经网络里通常仍简称线性层（见 [21-线性层-激活函数-与网络深度](21-线性层-激活函数-与网络深度.md)）。
- **线性变换**：用矩阵乘法把输入向量投影到新坐标空间。加入偏置后严格说是仿射变换，但神经网络里通常仍简称线性层（见 [21-线性层-激活函数-与网络深度](21-linear-layer-activation-network-depth.md)）。

## 四、一句话总结

标量、向量、矩阵、张量是不同维度的"数字容器"，点积和矩阵乘法是神经网络的"原子运算"——理解它们，后面的线性层、注意力、梯度就都是同一种语言的组合。
