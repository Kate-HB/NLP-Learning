# 25 反向传播与链式法则

> 一句话：神经网络是层层套娃的复合函数，反向传播用链式法则把"最终损失"的贡献一步步传回每一层的每个参数。


## 前置知识

- 先读 [24-梯度-梯度下降-与学习率](24-梯度-梯度下降-与学习率.md)。
- 先读 [24-梯度-梯度下降-与学习率](24-gradient-descent-learning-rate.md)。
- 会"复合函数求导"这个高中概念即可。

## 一、直观含义

神经网络是一条流水线：输入 → 第一层 → 第二层 → … → 输出 → 算损失。参数在最前面的层，损失在最后面——**中间的差异怎么传回去**？

反向传播的做法是：从最后一层开始，把"损失对输出"的敏感度，一层一层往回传。每一层都告诉前一层"你这边动一下，最终损失会变多少"。

## 二、具体例子

链式法则：`L = f(g(x))`，则 `dL/dx = f'(g(x)) · g'(x)`——**各层局部导数相乘**。

- 前向：`z = w·x`，`L = (z − y)²`。
- 反向：`dL/dz = 2(z − y)`；`dz/dw = x`；所以 `dL/dw = 2(z − y) · x`。
- 这个 `dL/dw` 就是 w 的梯度，交给优化器去更新。

## 三、技术要点（严谨部分）

### 1. 链式法则（Chain Rule）

- 复合函数的导数可以由各层局部导数**相乘**得到。
- 神经网络由许多连续变换组成，反向传播正是用它把最终损失的影响逐层传回参数。

### 2. 反向传播（Backpropagation）

- 利用链式法则**从损失向前面各层计算梯度**的过程。
- 名字的由来：信息流方向与前向相反——前向从输入到输出，反向从损失回到参数。

### 3. 为什么"深"会梯度消失

- 链式法则是"一路相乘"。若每层局部导数都小于 1，乘很多层后梯度趋近 0 → 前面层几乎学不动。
- 这就是 RNN 长序列早期信息衰减、以及 Transformer 要用残差连接（见 [43-Residual-LayerNorm-Dropout-与-Add-Norm](43-Residual-LayerNorm-Dropout-与-Add-Norm.md)）的原因之一。
- 这就是 RNN 长序列早期信息衰减、以及 Transformer 要用残差连接（见 [43-Residual-LayerNorm-Dropout-与-Add-Norm](43-residual-layernorm-dropout-add-norm.md)）的原因之一。

### 4. 前向与反向的关系

- **前向**：算预测、算损失。
- **反向**：算梯度、更新参数。
- 一次训练迭代 = 前向 + 反向 + 优化器更新。

## 四、一句话总结

反向传播 = 从损失倒着走一遍网络，用链式法则把梯度逐层算出来；没有它，前面层的参数就不知道该往哪调。
