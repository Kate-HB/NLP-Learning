## 二、八组辨析

### 1. Token、Word、Character

| 概念 | 定义 | 特点 |
|---|---|---|
| Character | 书写字符 | 汉字、字母、标点 |
| Word | 语言学上的词 | 有语法/语义功能 |
| Token | 模型实际处理单位 | 可能一个字/词/子词/标点 |

- 三者可能一一对应，也可能完全不同。模型只认 Token，不认"人眼里的词"（详见 [09](09-Token-与-Tokenizer.md)、[10](10-三种分词粒度.md)）。
- 三者可能一一对应，也可能完全不同。模型只认 Token，不认"人眼里的词"（详见 [09](09-token-and-tokenizer.md)、[10](10-three-tokenization-granularities.md)）。

### 2. Tokenizer Model 与 Transformer Model

| | Tokenizer Model | Transformer Model |
|---|---|---|
| 是什么 | 分词算法 + 词表 + 合并规则 | 神经网络参数 |
| 负责 | 文本 ↔ Token ID | 表示与预测 |
| 语义理解 | 不负责 | 负责 |

- 前者是统计过程、后者是神经网络；前者靠后者识别，后者依赖前者给对的 ID（详见 [11](11-子词算法-BPE-WordPiece-Unigram-SentencePiece.md)）。
- 前者是统计过程、后者是神经网络；前者靠后者识别，后者依赖前者给对的 ID（详见 [11](11-subword-algorithms-bpe-wordpiece-unigram-sentencepiece.md)）。

### 3. Token Embedding 与 Hidden State

| | Token Embedding | Hidden State |
|---|---|---|
| 来源 | 查表得到 | 多层上下文计算后 |
| 上下文相关 | 否（初始） | 是 |
| 角色 | 模型输入 | 内部表示 |

- "Embedding"是更宽泛的词，也可指上下文化 Token 向量或句向量，**不能一概等同于模型输入**（详见 [34](34-Token-Embedding-与输入表示相加.md)、[64](64-上下文嵌入-句子嵌入-与对比学习.md)）。
- "Embedding"是更宽泛的词，也可指上下文化 Token 向量或句向量，**不能一概等同于模型输入**（详见 [34](34-token-embedding-input-adding.md)、[64](64-contextual-sentence-embedding-contrastive.md)）。

### 4. Attention Mask、Causal Mask、MASK Token、Loss Mask

| 掩码 | 控制对象 | 一句话 |
|---|---|---|
| Attention Mask | 输入有效性 | 1=有效，0=PAD |
| Causal Mask | 注意力方向 | 不能看未来 |
| MASK Token | 输入内容 | MLM 的替换符号 |
| Loss Mask | 损失位置 | -100 不计损失 |

- 四者管的是"输入有效性 / 注意力方向 / 输入内容 / 损失位置"四件事（详见 [40-四种掩码辨析](40-四种掩码辨析.md)）。
- 四者管的是"输入有效性 / 注意力方向 / 输入内容 / 损失位置"四件事（详见 [40-四种掩码辨析](40-four-masks-distinguished.md)）。

### 5. Self-Attention 与 Cross-Attention

- **Self-Attention**：Q、K、V 来自**同一序列**。
- **Cross-Attention**：Query 来自 **Decoder**，Key/Value 来自 **Encoder 输出**。
- 一句话：自己看自己 vs Decoder 看 Encoder（详见 [39](39-Self-Attention-与-Multi-Head-Attention.md)、[45](45-Decoder-的完整结构.md)）。
- 一句话：自己看自己 vs Decoder 看 Encoder（详见 [39](39-self-attention-multi-head-attention.md)、[45](45-decoder-architecture.md)）。

### 6. Encoder 与 Decoder

| | Encoder | Decoder |
|---|---|---|
| 重点 | 完整输入 → 上下文化表示 | 可见前文 → 下一个 Token |
| 可见性 | 通常双向 | 因果（单向） |
| 特殊 | — | 交叉注意力读源序列 |

### 7. MLM 与 CLM

- **MLM**：恢复被随机遮盖的 Token，可用**左右**上下文（双向，练 Encoder）。
- **CLM**：根据**左侧**前文预测下一个 Token，不能看未来（单向，练 Decoder）。
- 详见 [49](49-自监督学习-与-MLM.md)、[50](50-CLM-与-NSP.md)。
- 详见 [49](49-self-supervised-learning-mlm.md)、[50](50-clm-nsp.md)。

### 8. Pretraining 与 Fine-tuning

- **Pretraining**：大规模通用语料上学**通用能力**。
- **Fine-tuning**：在已有权重上适配**任务或领域**。
- 两者都是训练，只是起点、数据规模和目标不同（详见 [07](07-预训练-微调与LLM.md)、[52](52-微调-PEFT-领域适应-与知识蒸馏.md)）。
- 两者都是训练，只是起点、数据规模和目标不同（详见 [07](07-pretraining-finetuning-and-llms.md)、[52](52-finetuning-peft-domain-adaptation-distillation.md)）。

## 三、一句话总结

Tokenizer Model 不管语义、Token Embedding 不带语境、四个 Mask 管四件事、两种 Attention 一个看自己一个看源——这些边界清晰了，Transformer 就串起来了。
