# 63 抽取式问答、生成式问答与幻觉

> 一句话：抽取式问答从原文里"框出"答案片段，生成式问答让模型"写出"答案；幻觉是模型生成了流畅但缺乏依据的内容。

## 一、直观含义

- **抽取式问答（Extractive QA）**：给模型一段上下文和一个问题，让它指出**答案在原文第几个字到第几个字**——像"用荧光笔划出答案"。
- **生成式问答（Generative QA）**：让模型**自己组织语言**回答——像"口述答案"，可能和原文一字不差，也可能完全是自己写的。

## 二、具体例子

上下文："苹果在 1976 年成立于加利福尼亚州，创始人是乔布斯。" 问题："苹果什么时候成立？"

- 抽取式：答案 = 原文中的"1976 年"（起止 Token）。
- 生成式：模型回答"苹果成立于 1976 年。"——可能多写一句"由乔布斯创立"。

## 三、技术要点（严谨部分）

### 1. 抽取式问答（Extractive QA）

- 要求答案是上下文中的**连续片段**。
- 模型为每个 Token 预测**成为答案起点**和**成为答案终点**的分数。
- **答案跨度（Answer Span）**：答案在上下文中的连续起止范围。

### 2. 字符偏移与 Token 换算

- 训练数据的答案常以原文中的**字符起点和终点**保存。
- **字符偏移（Character Offset）**：字符在原文中的位置。
- 预处理需要借助 **Offset Mapping** 把字符范围映射成 Token 起止索引，才能监督模型的 Token 级预测（见 [18-偏移映射与词-ID-映射](18-偏移映射与词-ID-映射.md)）。
- 预处理需要借助 **Offset Mapping** 把字符范围映射成 Token 起止索引，才能监督模型的 Token 级预测（见 [18-偏移映射与词-ID-映射](18-offset-mapping-word-id-mapping.md)）。

### 3. 长上下文的处理

- 长上下文通常要**切成多个有重叠的窗口**（滑动窗口，Sliding Window），再将各窗口候选答案合并。
- 训练时：如果答案不在某个窗口内，该窗口应使用数据集约定的**"无答案"位置**，不能伪造一个普通文本跨度。
- 验证时：保留每个窗口所属的**原始样本 ID** 与有效 Offset Mapping，才能把 Token 预测还原成原文答案。

### 4. 怎么选最终答案

⚠️ 不能简单地分别取最高起点和最高终点——二者组合后可能**终点早于起点、跨越特殊 Token 或长度不合理**。

- 通常先从高分起点与终点中组合候选，只保留**有效跨度**。
- 再用**起点与终点 Logits 之和**等联合分数比较。
- 同一问题的多个窗口据此汇总候选。
- ⚠️ 跨窗口分数未必经过严格校准，这种直接排序是常见**启发式方法**——不能把不同窗口各自的 Softmax 概率当成天然可比。
- 若任务允许无答案（如 SQuAD v2），还要把**最佳文本跨度**与**无答案分数**比较。

### 5. 生成式问答（Generative QA）

- 由模型**逐 Token 生成**答案。
- 能综合、解释、改写。
- 风险：答案不一定是原文片段，**更容易产生无依据内容**。

### 6. 幻觉（Hallucination）

- 模型生成了**流畅、看似合理但缺乏输入或可靠事实支持**的内容。
- **不是简单的语法错误，而是内容依据问题**。
- 检索、引用、事实核验和任务约束能**降低风险**，但不能保证完全消失。

### 7. 两种 QA 的对比

| | 抽取式 QA | 生成式 QA |
|---|---|---|
| 答案来源 | 原文片段 | 模型自组织 |
| 确定性 | 较高、可溯源 | 灵活但可能无据 |
| 适用 | 需要引用原文 | 开放式、综合回答 |
| 风险 | 抽错范围 | 幻觉 |

## 四、一句话总结

抽取式问答用起止分数"框"答案、靠偏移映射换算坐标、长文本要滑动窗口；生成式问答自由生成但容易幻觉——"流畅"不代表"有依据"。
