# 02 NLP 的主要任务

> 一句话：NLP 有一批"标准题型"，模型在这个统一的 Transformer 骨架上换不同的输出方式来完成它们。

## 一、直观含义

把 NLP 任务想象成学校的各科考试：同样是"读一篇短文"，语文考"这篇文章什么感情"（分类），英语考"翻译成中文"（翻译），数学考"文中第几行是答案"（问答）。题型不同，但都要先"读懂文本"。下面就是这些"题型"。

## 二、具体例子

- 一条外卖评论"这家店的排骨特别咸" → 情感分类判为"负面"。
- 一句话"王小明在北京的谷歌工作" → NER 抽出人名"王小明"、地名"北京"、机构"谷歌"。
- "Bonjour, comment ça va?" → 翻译成"你好，最近怎么样？"
- 一篇 500 字的新闻 → 摘要成 50 字。

## 三、技术要点（严谨部分）

### 文本理解类

- **文本分类（Text Classification）**：为整段文本预测一个或多个类别。如情感正负、新闻主题、用户意图。
- **序列标注（Sequence Labeling）**：为序列中的**每个词或 Token** 预测一个标签。典型任务：
  - **NER**（命名实体识别）：识别人名、地名等实体。
  - **POS**（词性标注）：判断名词、动词等语法类别。
  - **Chunking**（句法分块）：识别名词短语等局部结构。
- **信息抽取（Information Extraction，IE）**：从非结构化文本中抽出实体、关系、事件等结构化信息。NER 是它的基础任务之一。
  - **非结构化文本**：没有固定字段和严格模式；**结构化信息**：按明确字段、类别组织，便于数据库存储。

### 文本生成类

- **机器翻译**：把一种语言转为另一种，尽量保持语义、语气和术语。
- **文本摘要**：把长文本压成短文本，保留重要信息、减少冗余。
- **问答（QA）**：根据问题和已有知识给答案。答案可以从原文抽取，也可以由模型生成。

### 建模与表示类

- **语言建模（Language Modeling）**：学习语言序列的概率规律——根据前文预测下一个 Token，或根据双向上下文恢复被遮盖的 Token。它是所有 Transformer 模型的"母题"。
- **嵌入（Embedding）**：把离散对象映射为连续数值向量。
  - **文本嵌入（Text Embedding）**：把文本表示为固定长度向量。向量是有顺序的一组数值；向量空间是这些向量所在的多维坐标空间。理想情况下，语义接近的文本在选定距离规则下也更接近。

### 检索与应用类

- **检索（Retrieval）**：从候选集合中找出与查询相关的内容。
- **语义搜索（Semantic Search）**：根据含义而不是只根据相同关键词检索文本。
- **知识库（Knowledge Base）**：供系统查询的外部事实、文档或结构化记录。
- **检索增强生成（RAG）**：先从知识库检索相关内容，再让生成模型依据检索结果回答问题。

## 四、一句话总结

NLP 任务可以归为四类"读、判、写、找"：分类判整段、标注判每个词、生成写新文本、检索找相关信息；理解、生成、嵌入、检索是它们共同的地基。
