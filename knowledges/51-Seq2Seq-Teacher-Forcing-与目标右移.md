# 51 Seq2Seq、Teacher Forcing 与目标右移

> 一句话：Seq2Seq 把输入序列映射成输出序列；训练时用"真实目标前文"当输入（Teacher Forcing），并把目标右移一位让模型"看前一个、猜下一个"。

- 先读 [33-三类架构的数据流](33-三类架构的数据流.md)、[46-自回归生成](46-自回归生成.md)。
- 先读 [33-三类架构的数据流](33-data-flow-of-three-architectures.md)、[46-自回归生成](46-autoregressive-generation.md)。

## 一、直观含义

**Teacher Forcing（教师强制）**像"跟读训练"：老师（正确答案）每句都先示范一遍，学生照着重读——**每个位置都用真实前文**，而不是用学生自己刚说的（可能是错的）内容。

因为正确答案全都在手上，所有位置的输入可以**一次备齐**，训练就能并行。它的代价是：训练时总看"标准答案"，推理时却要面对"自己写出来的（可能有错）内容"——这叫**暴露偏差**。

**目标右移**是把"教师示范"切成两半：Decoder 的输入装"此前的正确答案"，监督标签装"当前要猜的答案"——两者错开一位。

## 二、具体例子

翻译 "I love NLP" → "我爱NLP"，训练一个样本：

```
Encoder 输入: I love NLP
Decoder 输入（右移后）: <s> 我 爱 N
Decoder 标签:           我 爱 N L P
```

- Decoder 第 1 步：看 `<s>`，猜"我"。
- 第 2 步：看 `<s> 我`，猜"爱"。
- ……监督时，每一步的"前文"都是**真实的**（Teacher Forcing）。

## 三、技术要点（严谨部分）

### 1. Seq2Seq 学习

- **序列到序列（Sequence-to-Sequence，Seq2Seq）**：把输入序列映射为输出序列。
- 训练时：Encoder 读取源序列；Decoder 根据源表示和**正确目标前文**预测目标序列的下一个 Token。

### 2. Teacher Forcing（教师强制）

- 训练 Decoder 时，每个位置使用**真实目标前文**，而不是前一步模型自己的预测。
- 好处：
  1. 所有目标位置的输入都能提前准备 → **并行训练**。
  2. 避免早期错误在一次训练样本中不断累积。
- 代价——**暴露偏差（Exposure Bias）**：
  - 训练时模型总看到正确前文。
  - 推理时模型必须面对自己可能错误的输出。
  - 两种分布不完全一致 → 训练与推理条件错位。

### 3. 目标右移（Target Shifting）

- 让 Decoder **输入表示"此前的正确目标"**，让**同一位置的监督标签表示"当前要预测的目标"**。
- 本质：**Decoder 输入与标签错开一个目标位置**。
- 序列开头用什么起始 ID 由模型决定：可能是 BOS、专门的 Decoder Start Token，某些模型还会复用 PAD 作为起始 ID。
  - ⚠️ 因此"目标右移 = 固定加入 BOS"并不准确。

### 4. 两种"下一 Token"训练的对齐区别

- **Seq2Seq（Encoder-Decoder）**：根据标签构造**右移后的 Decoder 输入**（输入和标签就是两份不同的序列）。
- **CLM（Decoder-only）**：常让**输入 ID 与标签表面相同**，在**损失计算**中用位置 i 的 Logits 对齐位置 i+1 的标签。
- 二者都在学习"下一个 Token"，但**具体对齐机制不能混为一谈**；也不能表述成"把 Logits 向右移动"（那是错误理解，见 [50-CLM-与-NSP](50-CLM-与-NSP.md)）。
- 二者都在学习"下一个 Token"，但**具体对齐机制不能混为一谈**；也不能表述成"把 Logits 向右移动"（那是错误理解，见 [50-CLM-与-NSP](50-clm-nsp.md)）。

## 四、一句话总结

Seq2Seq 是"序列到序列"，Teacher Forcing 用真实前文让训练并行（换来暴露偏差），目标右移让"输入 = 此前答案、标签 = 当前答案"错开一位——三者共同支撑生成模型的训练。
