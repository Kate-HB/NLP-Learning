# 35 位置编码：绝对、正弦、相对、RoPE

> 一句话：注意力本身不分先后，位置编码就是给模型注入"顺序感"的方法——有绝对位置、正弦函数、相对位置、RoPE 等做法，它们影响模型对长文本的适应力。


## 前置知识

- 先读 [34-Token-Embedding-与输入表示相加](34-Token-Embedding-与输入表示相加.md)。
- 先读 [34-Token-Embedding-与输入表示相加](34-token-embedding-input-adding.md)。
- 不需要会算正弦余弦，理解"生成固定向量的函数"即可。

## 一、直观含义

给每个词一个"座位号"。问题是：怎么把座位号变成向量？

- **绝对位置**：直接说"我是第 5 位"。
- **位置嵌入**：给每个位置配一个可学习向量，训练出来。
- **正弦编码**：用不同频率的正弦/余弦函数生成位置向量，**不需要学**，还能让"相邻位置"向量自然相似。
- **相对位置**：比起"我是第 5 位"，更关心"你离我 3 位远、在左边"。
- **RoPE（旋转位置编码）**：把位置信息"拧"进 Query 和 Key 的向量里——通过旋转向量分量，让注意力直接感知相对距离。现代 Decoder-only 模型爱用它。

## 二、具体例子

- 早期 BERT：`pos_embedding(0) + token_embedding("我")`——每个位置一个可学习向量，绝对位置。
- 原始 Transformer（Attention Is All You Need）：用正弦余弦函数生成固定位置向量，不需要训练。
- GPT 系列：也用可学习的位置嵌入。
- 现代 LLM（如 Llama、GPT-4 等）常用 RoPE：它不显式相加，而是在算注意力点积时，让"距离远的位置"自然匹配不上，"距离近的"匹配得上。

## 三、技术要点（严谨部分）

### 1. 为什么必须要有位置信息

- 注意力计算是对"所有位置对"做点积，它**不知道先后顺序**。
- 若不加位置信息，"我打你"和"你打我"在模型眼里完全一样。
- 因此必须引入位置表示。

### 2. 几类位置方法

| 方法 | 做法 | 特点 |
|---|---|---|
| 绝对位置（Absolute） | 直接表示"这是第几个位置" | 简单直观 |
| 位置嵌入（Position Embedding） | 每个位置一个可学习向量，与 Token Embedding 相加 | BERT/GPT 常用 |
| 正弦位置编码（Sinusoidal） | 不同频率的正弦/余弦生成固定向量 | 不需学习 |
| 相对位置（Relative） | 关注两个 Token 相距多远、方向如何 | 对长度更鲁棒 |
| RoPE（旋转位置编码） | 旋转 Q、K 的向量分量，把相对位置融入注意力 | 现代 Decoder-only 常用 |

### 3. 位置方法为什么重要

- 影响模型对**长文本**和**超出训练长度位置**的适应能力。
- 例如：只训过 2048 token 的模型，输入 4096 token 时，超出训练范围的位置表示"没见过"，表现可能骤降。

### 4. 轴向位置编码（Axial）

- 把一个很大的位置表示分解到多个轴上，再组合，以减少超长序列位置参数的存储成本。
- 它优化的是**位置表示**，不是注意力匹配本身。

## 四、一句话总结

位置编码给注意力注入"顺序感"：绝对/正弦/嵌入是"我是第几位"，相对/RoPE 是"你离我多远"；选哪种位置方法，直接影响模型能不能适应长文本。
