# 26 优化器 Adam、AdamW 与学习率调度

> 一句话：优化器决定"按梯度怎么更新参数"，Adam 用梯度的一阶/二阶移动平均自适应调整每步大小，AdamW 把权重衰减和梯度更新分开，是 Transformer 微调标配；学习率调度让学习率随训练过程变化。

## 一、直观含义

普通梯度下降是"每次都按固定步长走"。但真实山坡坑坑洼洼：

- 有些方向坡度抖（震荡大），有些方向又缓又滑。
- **Adam** 像一位有"步速记忆"的登山者：它记住"最近大致往哪走"（方向），也记住"最近步子抖不抖"（尺度），据此给每个参数调整合适的步长——抖的方向小步走，顺的方向大步走。
- **AdamW** 在 Adam 基础上，把"防止参数膨胀"的权重衰减（正则化）单独拿出来处理，效果更稳。
- **学习率调度**：像"热身再加速再收尾"——先小步热身（Warmup），再正常走，后段逐步减速。

## 二、具体例子

- AdamW + `learning_rate=5e-5` 是 BERT 微调的经典配置。
- 线性调度：学习率从 `5e-5` 随训练步数线性降到 0，配合前几百步的 Warmup。
- 调度器的"总步数" = 训练轮数 × 每个 Epoch 的 Batch 数（见 [27-Epoch-Step-与梯度累积](27-Epoch-Step-与梯度累积.md)）。
- 调度器的"总步数" = 训练轮数 × 每个 Epoch 的 Batch 数（见 [27-Epoch-Step-与梯度累积](27-epoch-step-gradient-accumulation.md)）。

## 三、技术要点（严谨部分）

### 1. 优化器（Optimizer）

- 根据梯度更新参数的算法。梯度只告诉你"方向"，优化器决定"怎么动"。

### 2. Adam（Adaptive Moment Estimation）

- 维护两种移动平均：
  - **一阶矩**（梯度的移动平均）：反映大致更新方向。
  - **二阶矩**（梯度平方的移动平均）：反映梯度尺度。
- 再据此**自适应调整不同参数的更新幅度**——每个参数有自己的有效学习率。

### 3. AdamW

- 把**权重衰减**与梯度更新更合理地**分离**。
- 是 Transformer 微调中的常见优化器。
- 权重衰减（Weight Decay）：通过抑制参数无限增大来帮助正则化。

### 4. 学习率调度（Learning Rate Schedule）

- 让学习率随训练过程变化，常见：
  - **预热（Warmup）**：训练初期从较小学习率逐步增加，降低开始阶段更新不稳定的风险。
  - **线性衰减**：从峰值逐步降到 0。
  - 总步数 = epochs × len(train_dataloader)，决定衰减的斜率。

### 5. 实践要点

- Batch Size 翻倍时，学习率通常也翻倍（经验法则）。
- 训练循环中每步：`loss.backward()` → `optimizer.step()` → `scheduler.step()` → `optimizer.zero_grad()`（顺序不能乱）。

## 四、一句话总结

梯度指方向、优化器决定怎么走、调度器决定每步走多大并随时间变化；AdamW 是 Transformer 微调的事实标准，配合 Warmup + 线性衰减最常用。
