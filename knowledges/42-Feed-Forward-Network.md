# 42 Feed-Forward Network

> 一句话：FFN 是每个 Token Block 里"对每个位置独立做非线性变换"的子层——注意力管"词与词之间"，FFN 管"每个词内部"。

## 一、直观含义

注意力让每个词"看完别人"（信息交换完成），接下来需要"自己消化"——把看来的信息做更复杂的加工。FFN 就是这一步"消化车间"：

1. 先把维度**撑大**（768 → 3072），给变换留出更多表达空间。
2. 过激活函数（加非线性）。
3. 再压回隐藏维度（3072 → 768）。

## 二、具体例子

BERT 里每个 Block 的 FFN：

```
x（768 维）
 → 线性层 768 → 3072
 → GELU 激活
 → 线性层 3072 → 768
 → 输出
```

每个位置（每个 Token）都走这一遍，**用的是同一组参数**，但因为输入不同，输出也不同。

## 三、技术要点（严谨部分）

### 1. 定义

- **FFN（前馈神经网络）**：每个 Transformer Block 中**对每个位置独立应用**的非线性网络。
- 通常结构：先把隐藏维度扩展成更大的中间维度 → 激活函数 → 投影回隐藏维度。

### 2. 与注意力的分工

| | 注意力 | FFN |
|---|---|---|
| 负责 | 不同 Token 之间的信息交换 | 每个 Token 内部的特征变换 |
| 输入 | 整个序列 | 单个位置的向量 |
| 类比 | 开班会交流 | 各自消化笔记 |

> 经典 Transformer Block 通常同时包含二者，它们承担**不同作用**——一个管词间、一个管词内。

### 3. 参数共享的细节

- FFN 对所有位置使用**同一组参数**。
- 但每个位置输入的隐藏状态不同 → 输出也不同。
- 也就是说：同一台机器，处理不同的原料，产出不同。

### 4. 为什么中间要"撑大再压回"

- 更高的中间维度给线性变换提供更大自由度，让网络能学到更丰富的特征组合。
- 常见的中间维度通常是隐藏维度的 4 倍。

## 四、一句话总结

注意力让词之间交流，FFN 让每个词自己消化；FFN = 撑大 → 激活 → 压回，同参数、逐位置应用，是 Block 里"管词内"的那一半。
