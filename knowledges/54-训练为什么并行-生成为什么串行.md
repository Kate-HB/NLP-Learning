# 54 训练为什么并行、生成为什么串行

> 一句话：训练时正确答案全在手，可以一次构造所有位置并矩阵并行；推理时未来答案未知，下一步依赖上一步的输出，只能串行。


## 前置知识

- 先读 [46-自回归生成](46-自回归生成.md)、[51-Seq2Seq-Teacher-Forcing-与目标右移](51-Seq2Seq-Teacher-Forcing-与目标右移.md)。
- 先读 [46-自回归生成](46-autoregressive-generation.md)、[51-Seq2Seq-Teacher-Forcing-与目标右移](51-seq2seq-teacher-forcing-label-shift.md)。

## 一、直观含义

- **训练**：相当于"对着标准答案做整卷"——所有位置该输出什么全都知道，所以可以一次把整卷的输入备好、一起算。
- **推理**：相当于"盲写"——第 2 个字还没写，第 3 个字就无从谈起；每一步都必须等上一步真的写出来。

## 二、具体例子

训练翻译 "I love NLP" → "我爱NLP"：

- Decoder 输入一次备齐：`<s> 我 爱 N`（真实前文）。
- 一个前向把所有位置（看 `<s>` 猜"我"、看"我"猜"爱"……）**同时**算出来，一起算损失。

推理同一个任务：

- 第 1 步：`<s>` → 生成"我"。
- 第 2 步：`<s> 我` → 生成"爱"。
- ……必须一步步来，无法一步到位。

## 三、技术要点（严谨部分）

### 1. 训练为什么能并行

- 训练 CLM 或 Seq2Seq Decoder 时，**整段正确目标已知**。
- Seq2Seq：可先构造**右移后的目标输入**（见 [51](51-Seq2Seq-Teacher-Forcing-与目标右移.md)）。
- Seq2Seq：可先构造**右移后的目标输入**（见 [51](51-seq2seq-teacher-forcing-label-shift.md)）。
- CLM：可在**损失内部**错开 Logits 与标签（见 [50](50-CLM-与-NSP.md)）。
- CLM：可在**损失内部**错开 Logits 与标签（见 [50](50-clm-nsp.md)）。
- 二者再配合**因果掩码**，就能一次构造所有训练位置并用矩阵并行计算预测。

### 2. 推理为什么通常串行

- 推理时**没有未来正确答案**。
- 第 t+1 步输入依赖第 t 步**实际生成**的 Token。
- 必须先生成前一个，再生成后一个。

### 3. 三个概念的严格区分

| 概念 | 管的是什么 |
|---|---|
| 因果掩码 | 能看哪些位置 |
| 并行计算 | 硬件能否同时算多个位置 |
| 自回归依赖 | 后一步输入是否依赖前一步输出 |

> 三者**相关，但不是同一个概念**。训练也能用因果掩码（限制可见性），但因为目标已知所以仍能并行；推理因为目标未知所以串行。

### 4. 一个重要推论

- 正因为推理串行，才催生了 **KV Cache** 这种"少重复计算"的优化（见 [56-KV-Cache-与-Context-Window](56-KV-Cache-与-Context-Window.md)）。
- 正因为推理串行，才催生了 **KV Cache** 这种"少重复计算"的优化（见 [56-KV-Cache-与-Context-Window](56-kv-cache-context-window.md)）。

## 四、一句话总结

训练有"标准答案"在手 → 目标可提前备齐 → 并行；推理没有未来答案 → 一步等一步 → 串行；因果掩码管"看什么"，并行/串行是"能不能同时算"，自回归依赖管"要不要等上一步"。
