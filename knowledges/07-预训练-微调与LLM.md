# 07 预训练、微调与 LLM

> 一句话：预训练让模型先读尽天下书学会"通用语言能力"，微调再针对具体任务小修小补，这就是当代 NLP 的标准流水线；LLM 是把这条流水线规模放大的产物。

## 一、直观含义

把模型训练想成"培养一名员工"：

1. **预训练**：先送他去上学，读海量通用书籍，学会语言本身（语法、常识、表达方式）。此时他什么都会一点，但还没针对任何具体岗位。
2. **微调**：到岗后，用一小部分"岗位手册"（任务数据）再培训一下，比如学会"把新闻分类成科技/体育"。
3. **迁移学习**：上学和上岗之间知识转移这个思路的总称。

LLM（大语言模型）就是"超大规模上学"的产物：参数多、数据多、能力强。

## 二、具体例子

- 预训练：用几 TB 的网页、书籍让模型学会"中文怎么组织、什么词通常接什么词"。
- 微调：拿 4000 条带情感标签的评论再训 3 个 epoch，模型就从"通才"变成"情感分类专员"。
- 迁移学习：为什么微调只要几千条数据就够？因为预训练已经提供了通用表示，微调只是"最后一公里"。

## 三、技术要点（严谨部分）

### 1. 预训练（Pretraining）

- 在**大规模通用语料**上先学习语言规律。
- 不针对单一业务任务，学习的是**可迁移的通用表示和生成能力**。

### 2. 微调（Fine-tuning）

- 在预训练权重基础上，用**较小规模的任务或领域数据**继续训练。
- 让模型适应具体目标。注意：微调不是只训分类头，可以只更新 Head，也可以更新部分或全部骨干参数（详见 [52-微调-PEFT-领域适应-与知识蒸馏](52-微调-PEFT-领域适应-与知识蒸馏.md)）。
- 让模型适应具体目标。注意：微调不是只训分类头，可以只更新 Head，也可以更新部分或全部骨干参数（详见 [52-微调-PEFT-领域适应-与知识蒸馏](52-finetuning-peft-domain-adaptation-distillation.md)）。

### 3. 迁移学习（Transfer Learning）

- 把一个阶段学到的能力迁移到另一个任务。
- **预训练 + 微调就是 NLP 中最典型的迁移学习**。

### 4. 大语言模型（LLM）

- 通常指参数规模、训练数据和能力都较大的语言模型。
- 大多基于 Transformer，通过**下一个 Token 预测**或相关目标学习语言规律。
- ⚠️ "大"不是严格的参数阈值。LLM 的关键不只是参数数量，还包括：数据规模、训练目标、上下文能力、对齐方法、推理方式。

## 四、一句话总结

预训练提供"通用语言能力"，微调把能力转化为"任务能力"，迁移学习是这套思路的名字，LLM 是把规模做大的自然延伸——这是理解后面所有模型的一根主线。
